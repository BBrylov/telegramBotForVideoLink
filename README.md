# YouTube Video Downloader Telegram Bot

Бот для скачивания видео с YouTube по ссылке. Сохраняет видео в формате MP4 с метаданными в имени файла.

## Функциональность
- Загрузка видео по ссылке YouTube
- Автоматическое формирование имени файла: `<канал>_<дата>_<название>.mp4`
- Логирование операций в файл `logs/bot.log`
- Проверка валидности ссылок

## Требования
- Python 3.10+
- Установленные зависимости:
```bash
pip install -r requirements.txt
```

## Настройка
1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен
2. В файле `settings.json` укажите:
```json
{
  "download_path": "/путь/для/сохранения",
  "telegram_token": "ВАШ_ТОКЕН"
}
```

## Запуск
```bash
python bot.py
```

## Структура проекта
```
├── bot.py             - Основной скрипт бота
├── config.py          - Загрузка конфигурации
├── downloader.py      - Загрузчик видео с YouTube
├── settings.json      - Конфигурационный файл
├── requirements.txt   - Зависимости
├── .gitignore         - Игнорируемые файлы
├── logs/              - Директория для логов
└── downloads/         - Директория для загруженных видео
```

## Пример использования
1. Отправьте боту команду `/start`
2. Отправьте ссылку на YouTube видео
3. Бот скачает видео и отправит подтверждение
